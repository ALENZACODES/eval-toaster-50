# 50 Words Exactly: an AI evaluation

Compares gpt-4-0314 (2023) and gpt-5 (2025) on the OpenAI Progress prompt "Tell a story in 50 words about a toaster that becomes sentient." Live page: https://alenzacodes.github.io/eval-toaster-50/

Responses are quoted verbatim from https://progress.openai.com/?prompt=10. Evaluation and page are original work.
